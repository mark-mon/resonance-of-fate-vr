HOW THE MOD IS BUILT
--------------------
- Based on the Star Ocean: The Last Hope mod (so4vr 0.3.7). RoF is the same ASKA engine generation: the render
  thread command processor, job dispatch, per-view constant blocks, camera object and screen config are the same
  code with shifted offsets. Game-specific files keep their so4_* names (so4_stereo.cpp, so4_camera.cpp,
  so4_headtrack.cpp, so4_hud.cpp, render_res.cpp); addresses were remapped (see FINDINGS.md).
- New in rofvr: dllmain.cpp DeferredGameHooks (game-code hooks wait until SteamStub has decrypted .text AND the
  page is executable again - hooking in DllMain fails), rof_input.cpp (pad object diagnostics), PatchAligned
  (constant-upload matrix scan only at 16-byte positions: 30 -> 60 fps), VRS eye selection for both-replay stereo.
- RE tooling (re/): rebuild_pe.py (memory dump -> PE), index.py + q.py (xref index), match.py / findmatch.py /
  side.py (match SO4 functions to RoF by code shape, side-by-side disassembly), dispfind.py / dispany.py,
  rtti_rof.py / rtti_so4.py, vtmatch.py. Dumps: agent\captures\002\rof_dump0.bin (RoF),
  D:\vrconversions\starocean4\agent\captures\003\so4_dump0.bin (SO4).

TEST AUTOMATION (agent\tools\rof.ps1)
--------------------------------------
- No gamepad on the test PC and the game never polls XInput without one, so tests use keyboard + mouse:
  Enter-ROFGame goes from a fresh start to the field with save Data 1 (Base): Enter skips the intro; title needs
  clicks + Enter as a virtual key (retried until the orange LOAD header is detected); a left click = confirm;
  W/A/S/D = directions ("Load save data?" defaults to No -> W -> click); "Load complete." needs one more click.
- Window shots: Save-ROFShot. Eye dumps: config DebugDumpEyesAt = N, or F11 with StereoDiag = 1 (also for the
  user in the headset; F12 always marks the log)
  (files rofvr_eye_*.bmp in the game folder; 39 MB each at headset size).
- Upload capture (one frame of constant-buffer uploads): with CameraHook = 1, create rof_upl_now.txt in the game
  folder -> rof_upl.bin; analyse with tools/upl.py, blk.py, blk2.py from the source snapshot.

CONFIG (config.txt in the game folder; written with comments on first run)
-------------------------------------------------------------------------
RenderMode = Native (default) / Flat; ReplayRawFromPass1 = 1 + ReplayPass1Nearest = 1 (flash fix, 0.1.8); ReplayDupFix = 0 (default since 0.1.5 - must stay off in RoF); RenderResolution = Auto / Game / WxH; RenderScale; StereoBothReplay = 1

Sharpen; MotionBlur = 0. Hotkeys: F8 Flat <-> Native, F9 recentre, F10 HUD panel, Insert menu.
